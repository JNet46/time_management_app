# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

[👉🏾👉🏾👉🏾 Include at least at least 1, but no more than 3, user roles.]

The Student: Juggling classes, assignments, exams, and a social life. They need a tool to organize academic deadlines, schedule study sessions, and avoid last-minute cramming.
The Professional / Freelancer: Managing multiple projects, client meetings, and tight deadlines. They need to prioritize high-impact work, track billable hours (or project time), and maintain a clear separation between work and personal life.
The Personal Growth Enthusiast: Focused on building habits, learning new skills, and achieving long-term personal goals (e.g., fitness, reading, side projects). They need a flexible tool to track progress and maintain consistency.

## Draft User Stories

[👉🏾👉🏾👉🏾 Include at least at least 10 user stories in this format:]

1. As a Student, I want to input my assignment due dates and exam schedule, so that the Dynamic Timeline can automatically suggest and block out study sessions for me.
2. As a Professional/Freelancer, I want to categorize my tasks by client or project, so that I can easily see how much time I'm spending on each and prioritize my work accordingly.
3. As a Personal Growth Enthusiast, I want to create a recurring habit for "Morning Meditation," so that I can build a consistent mindfulness practice and track my streaks.
4. As a Professional/Freelancer, I want to use the Priority Matrix to quickly sort my daily tasks, so I can immediately identify what to work on first when I start my day.
5. As a Student, I want to start a "Focus Mode" session when I'm writing an essay, so that I can block out distractions and work in focused 45-minute intervals.
6. As any user, I want to view my productivity dashboard at the end of the week, so I can understand my work patterns and see where I can improve.
7. As a Professional/Freelancer, I want The Oracle to suggest the best time to schedule a demanding client call based on my historical energy levels, so that I can be at my sharpest.
8. As a Personal Growth Enthusiast, I want to link my daily "Practice Guitar" task to my long-term goal of "Learn to Play a Full Song," so I can see my progress and stay motivated.
9. As a Professional/Freelancer, I want to be able to drag and drop a scheduled task on the timeline to a new time, so that the app can intelligently adjust the rest of my schedule around it.
10. As a Student, I want to receive a notification 24 hours before a major assignment is due, so that I have a final reminder to review my work.
11. As any user, I want to add tasks using natural language (e.g., "Schedule a meeting with the team for tomorrow at 3 pm"), so that I can quickly capture my thoughts without navigating complex menus.
